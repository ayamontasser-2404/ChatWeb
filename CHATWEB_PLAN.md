# Project goal
this chat web will allow the user to send message and have reply from llm which train to be creeative teacher suggest how to soend your free time
## Component responsibilities
- main screen which contain sidebar , message input and messages display
- main screen will be our main coordinator 
- side bar will be have all user previous chat
- message input where user send his message
- message display where chat is held between user and reply from llm
## Chat behaviour
- The user can start a new chat.
- When starting a new chat, the current conversation is saved in the conversation history.
- The user can select an existing conversation from the sidebar and see its previous messages.
- The user can send a message and receive a predefined mock reply from the Creative Teacher.
- The user can start a new conversation without losing previous conversations.
## Acceptance criteria
- Previous conversations remain visible in the sidebar.
- The user can switch between existing conversations.
- The selected conversation displays the correct messages.
- The user can send a message and see a mock reply.
- Empty messages are not sent.
